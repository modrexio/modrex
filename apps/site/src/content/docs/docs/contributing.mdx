title: Contributing
description: Report a problem, suggest a feature, translate Modrex, or contribute code and documentation.
---

Modrex is open source and welcomes contributions of any size. Choose the path that matches what
you want to help with.

## Report a problem

Open a [bug report](https://github.com/modrexio/modrex/issues/new?template=bug_report.yml) with the
steps that caused the problem. Attach your Modrex log when possible; see
[Troubleshooting](/docs/troubleshooting#log-file-location) for its location.

## Suggest a feature

Open a [feature request](https://github.com/modrexio/modrex/issues/new?template=feature_request.yml)
and describe the problem the feature would solve.

## Translate Modrex

Use the [translation guide](https://github.com/modrexio/modrex/blob/main/TRANSLATING.md) to improve
an existing language or add a new one. Partial translations are welcome, and you do not need to
build Modrex or install its development tools.

The guide shows where language files live, how to find missing strings, how to choose a locale
filename, and how to submit your work for CI validation.

## Contribute code or documentation

The [developer contribution guide](https://github.com/modrexio/modrex/blob/main/CONTRIBUTING.md)
covers setup, repository checks, code style, commits, and pull requests.

If you are unsure where to start, ask in the
[Modrex Discord](https://discord.gg/tenzpx8JRM).
