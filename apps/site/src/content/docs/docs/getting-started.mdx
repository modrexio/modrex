## <OsIcon os="Windows" />Windows

Download [modrex_x86_64.exe](https://github.com/modrexio/modrex/releases/latest/download/modrex_x86_64.exe)
and run it. The installer is signed.

Or install it with winget:

```sh
winget install modrex
```

New versions can reach winget later than the direct download, because each one goes through
winget's own review first.

## <OsIcon os="Linux" />Linux

Download a package and install it:

| Platform       | Download                                                                                                     | Install                                |
| -------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| Linux .deb     | [modrex_x86_64.deb](https://github.com/modrexio/modrex/releases/latest/download/modrex_x86_64.deb)           | `sudo apt install ./modrex_x86_64.deb` |
| Linux .rpm     | [modrex_x86_64.rpm](https://github.com/modrexio/modrex/releases/latest/download/modrex_x86_64.rpm)           | `sudo dnf install ./modrex_x86_64.rpm` |
| Linux AppImage | [modrex_x86_64.AppImage](https://github.com/modrexio/modrex/releases/latest/download/modrex_x86_64.AppImage) | `chmod +x modrex_x86_64.AppImage`      |

Or let the install script pick and install the right package:

```sh
curl -fsSL https://modrex.net/install.sh | sh
```
