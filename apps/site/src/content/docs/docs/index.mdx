Modrex is a free, open-source desktop mod manager for Windows and Linux. Browse, install, and
organize mods from [ModWorkshop](https://modworkshop.net/) or Nexus Mods,
then launch the game modded or vanilla from the app.

![The Modrex installed mods list with folders and load order](../../../assets/screenshots/installed-mods-window.webp)

## Key features

- **Browse ModWorkshop and Nexus Mods** with catalog search, categories, tags, sorting, mod pages, and
  dependency info.
- **Install in one click** from `.pak`, `.zip`, `.7z`, `.rar`, `.tar.gz`, and `.tar.xz` files, then
  enable, disable, or remove mods. Multi-file archives are grouped as one mod.
- **Organize your library** into nested folders and reorder them by dragging.
- **Update checks** detect out-of-date mods so you can update them selectively or all
  at once.
- **Launch modes** let you start with managed mods enabled or use
    <a href={sitePath('/docs/concepts/launch-modes')}>Launch without mods</a> for the active game's
    supported mod targets.
- **Game detection** finds supported games across their launchers and picks up mods
  you added outside Modrex.
