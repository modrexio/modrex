## Launch modded

Click **Launch** in the top bar to start the active game with all enabled mods active. Modrex passes
your configured launch options to the game and hands off to your launcher.

For PAYDAY 3, pak mods load only when UE4SS is installed. See
[PAYDAY 3](/docs/games/payday-3#ue4ss).

## Launch without mods

Click the dropdown arrow next to **Launch** and select **Launch without mods**. For Ready or Not,
Modrex uses the game's Safe Mode for Pak mods. It leaves the shared Paks folder in place and does
not disable manually installed DLLs or scripts.

For other games, Modrex temporarily backs up the managed mod folders.

When a backup-based session closes, Modrex automatically detects this and restores your mods. While a vanilla
session may still be running, a banner across the top reminds you mods are hidden and offers a
**Restore mods** button - use it if Modrex closed before it could restore automatically (for example,
if the app itself was closed mid-session).

See [Launch modes](/docs/concepts/launch-modes) for how target-scoped backups and restore behavior
work.

## Launcher support

To override the detected launcher for the active game, go to **Settings > Game > Launcher** and
select one manually.
