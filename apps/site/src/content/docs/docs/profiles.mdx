A profile is one setup of a game: its mods, whether each is on, its folders and its load order.
Each profile has its own mods. When you switch, the mods of the profile you leave are put away in
the game's `.modrex` folder, where the game doesn't load them, and Modrex's installed list shows
only the profile you switched to.

The profile menu sits in the top bar, left of **Launch without mods** and **Launch modded**. It
shows the active profile's name, or **No profile** before you have one. Profiles are per game and
per copy of a game, so a Steam and an Xbox install of the same game each keep their own.

## Your first profile

Open the menu and choose **Save current setup as a profile**. The name starts as Main. Save it
with the check button or Enter. It describes exactly what is installed, so it becomes the active
profile straight away.

Do this before trying anything else. Switching while no profile is active is refused, because the
mods it would put away would belong to no profile.

## Creating more

**New profile** adds a row to the menu where you type a name. A new profile starts over: no mods,
no folders. If loaders are installed, the row also offers **Keep loaders**, which lists them by
name. It's unchecked, so a new profile starts without loaders too. Check it when the mods you plan
to install need them. See [Loaders](#loaders) for what that means for each one.

**Duplicate**, on a profile's row, copies its mods, folders, load order and loaders under the name
"_profile_ copy". Both profiles then share the same installed files, so nothing is downloaded
again.

A name is only kept when you press the check button or Enter. The cross button or Escape drops
it. Clicking outside the menu closes it and saves nothing.

## Switching

Turn on the switch next to a profile. The menu stays open while Modrex works, and the button in
the top bar reads **Switching to** _name_ until it's done. Mods you left on are on again, in the
folders and order you left them.

A switch is refused while:

- the game is running, or a launch from Modrex is still waiting for the game to start
- mods are set aside for a launch without mods. Start the game normally once to bring them back,
  then switch.

## Mods and profiles

A mod you install goes into the active profile only. Installing a mod in one profile that another
profile already has gives each profile its own copy.

Turning a mod off keeps it in the profile, off. Removing it takes it out of every profile, which is
why the remove button reads **Remove from every profile** once a game has profiles.

A mod whose files are missing stays in the list whichever profile is active, until you reinstall
or remove it.

<Callout>
    Ready or Not keeps its Pak mods next to the game's own files, and Modrex never moves anything
    out of that folder. A Pak mod outside the active profile stays there, turned off and listed.
</Callout>

## Loaders

A loader such as PDML or UE4SS belongs to profiles like a mod does. To leave one out, Modrex moves
only the files that hook it into the game, and the loader is back as soon as you switch to a
profile that has it.

| Loader                   | What a profile without it puts away                            |
| ------------------------ | -------------------------------------------------------------- |
| PDML                     | The whole plugin, like any mod                                 |
| UE4SS                    | Its proxy DLL. The UE4SS folder and the mods in it stay        |
| SuperBLT (PAYDAY 2)      | `WSOCK32.dll`                                                  |
| SuperBLT (RAID: WWII)    | The files its install created, or its DLL for an older install |
| DAHM (PAYDAY: The Heist) | The files its install created                                  |

<Callout type="warning">
    Modrex can only tell which files belong to DAHM when Modrex installed it. A DAHM installed by
    hand, or by a version of Modrex older than profiles, stays in every profile. Reinstall it from
    Modrex to let profiles leave it out.
</Callout>

If you install a loader again while a profile has it put away, the new copy is the one you keep.

## Renaming and deleting

Hover a profile's row for its rename, duplicate and delete buttons.

Deleting asks first. It removes the profile together with the mods no other profile has. Deleting
the active profile leaves its mods installed, with no profile active.

## If a switch stops

A switch that is interrupted, for example by Modrex closing or a file being locked, leaves a banner:
"The switch to _name_ did not finish". Click **Finish switch** to complete it, or switch to any
other profile instead. Until then Modrex won't create profiles, and won't delete the one the switch
was heading for.

## Where profiles are stored

Everything lives in the game folder, in `.modrex`: the profiles themselves, the mods and loaders
other profiles put away, and the record of the active profile.

<Callout type="warning">
    Uninstalling the game in its store, or a cleanup that deletes everything that isn't part of the
    game, removes `.modrex` too, and with it your profiles and the mods they put away. Keep that
    folder if you move or reinstall the game.
</Callout>
